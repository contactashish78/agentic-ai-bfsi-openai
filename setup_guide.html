00Python for .NET / Java developers

You already know every idea in this setup. Python just uses different names for them.

Mental model. .venv + requirements.txt + pip install is the Python way of doing dotnet restore or mvn install, except the packages land inside the project folder instead of a global cache.

01Install Python

1

Install Python 3.12

5 min

Any version from 3.11 up works; 3.12 is what the session was tested with. If python --version already prints 3.11 or newer, skip to step 2.

Windows

  1. Download the installer from python.org/downloads.
  2. On the first screen tick “Add python.exe to PATH”, then click Install Now.

Or from a terminal:

winget install Python.Python.3.12

macOS

Use the installer from python.org, or Homebrew:

brew install python@3.12

Linux

sudo apt install python3.12 python3.12-venv

Close and reopen your terminal, then check:

Windows (PowerShell)

python --version
# Python 3.12.x

macOS / Linux

python3 --version
# Python 3.12.x
Windows: Microsoft Store opens instead? That is a Windows shortcut, not real Python. Turn off Settings → Apps → Advanced app settings → App execution aliases → python.exe / python3.exe, or use the Python launcher: py -3.12 --version.
macOS / Linux note. Use python3 wherever this guide says python until the virtual environment is active. After that, plain python works everywhere.

Also install

  • Git (optional): git-scm.com, or download the code as a ZIP instead.
  • An editor (optional): VS Code with the Python and Jupyter extensions from Microsoft. Not required: JupyterLab runs in your browser.

02Get the code

2

Clone or download the repository

2 min
git clone https://github.com/contactashish78/agentic-ai-bfsi-openai.git
cd agentic-ai-bfsi-openai

No Git? Open the repository page, choose Code → Download ZIP, unzip it, and open a terminal in that folder.

Use a short path without spaces, for example C:\code\agentic-ai-bfsi-openai. Long OneDrive paths can cause odd errors on Windows.

Every command from here on is run from this project folder.

03Create a virtual environment

3

Create and activate .venv

2 min

This creates a .venv folder inside the project holding a private copy of Python. You create it once; you activate it in every new terminal.

Windows · PowerShell

python -m venv .venv
.venv\Scripts\Activate.ps1

Windows · Command Prompt

python -m venv .venv
.venv\Scripts\activate.bat

macOS / Linux

python3 -m venv .venv
source .venv/bin/activate

Once it is active, your prompt starts with (.venv):

(.venv) PS C:\code\agentic-ai-bfsi-openai>
PowerShell says “running scripts is disabled on this system”? Allow locally created scripts for your user only, then activate again: 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
If company policy blocks this, use Command Prompt and activate.bat instead.
Forgot to activate? Packages would install into the global Python, and the notebooks would not find them. If the prompt has no (.venv), activate first.

04Install the packages

4

Install from requirements.txt

3–8 min
python -m pip install --upgrade pip
pip install -r requirements.txt

This installs (with their dependencies):

PackageWhy we need it
aisuite[openai,mcp]One simple client for many LLM providers; we use it with OpenAI. Also runs the tool-calling loop for us.
openaiThe official OpenAI SDK (Module 1 compares it with aisuite).
python-dotenvReads the .env file into environment variables.
pydanticTyped data classes for structured output (think DTOs with validation).
jupyter, ipykernelJupyterLab and the notebook kernel.
streamlitTurns a Python script into a web UI, used for the capstone harness.
Behind a corporate proxy or SSL inspection? If you see SSLError, CERTIFICATE_VERIFY_FAILED or connection timeouts, see Corporate network in Troubleshooting.

05Add your OpenAI API key

5

Create .env from the template

3 min
  1. Create a key at platform.openai.com/api-keys. The account needs a small amount of credit; the whole session uses well under $0.10 with gpt-4o-mini.
  2. Copy the template:

    Windows

    copy .env.example .env

    macOS / Linux

    cp .env.example .env
  3. Open .env in any text editor and replace the placeholder: 
    OPENAI_API_KEY=sk-proj-...paste-your-key-here...
# aisuite model string: provider:model
MODEL=openai:gpt-4o-mini
TEMPERATURE=0.2
MAX_STEPS=6
Treat the key like a password. No quotes, no spaces around =. Never paste it into a notebook cell, a screenshot or a chat. .env is listed in .gitignore, so Git will not commit it.
Why openai:gpt-4o-mini? aisuite model names are provider:model. Switching providers later is a one-line change here, much like changing a connection string.

06Check everything works

6

Run the setup check

1 min

With (.venv) active, run:

python check_setup.py

It checks the Python version, the virtual environment, every package, your .env, and makes one tiny API call (a few tokens). A good result looks like this:

[ OK ] Virtual environment: C:\code\agentic-ai-bfsi-openai\.venv
[ OK ] aisuite        0.2.0
[ OK ] openai         1.109.1

First run is slow? Endpoint security software often scans every new Python file the first time it is imported. A 30–60 second first start is normal on company laptops; later runs are fast.

08Python syntax you will see

You do not need to write Python in the session. This is enough to read every cell.

C#

Dictionary<string, object>
    CheckLoanStatus(string id)
{
    if (!loans.ContainsKey(id))
        return new() { ["found"] = false };
    var app = loans[id];
    return new() {
        ["found"] = true,
        ["status"] = app.Status,

    };
}

Python

def check_loan_status(application_id: str) -> dict:
    """Look up a loan application."""  # docstring
    if application_id not in loans:
        return {"found": False}
    app = loans[application_id]
    return {
        "found": True,
        "status": app["status"],
        "note": f"Updated {app['last_updated']}",
    }
PythonRead it as
Indentation instead of { }The indented lines are the block. No semicolons.
def name(x: str) -> dict:A method. Type hints are optional and not enforced at runtime, but aisuite reads them to build the tool schema.
"""docstring"""Like XML doc comments / Javadoc, except the LLM reads it: it becomes the tool description.
{"key": value}, [1, 2, 3]Dictionary and list literals, written exactly like JSON.
f"Hello {name}"String interpolation, like C# $"Hello {name}".
True / False / Nonetrue / false / null.
create(model=m, tools=[f], max_turns=5)Named arguments, like C# named parameters.
for msg in messages:foreach (var msg in messages)
[t.name for t in tools]A list comprehension: tools.Select(t => t.Name).ToList() / tools.stream().map(...).
@dataclass, @lru_cacheDecorators, similar to attributes / annotations, but they wrap the function or class.
from harness.tools import LOAN_TOOLSusing / import of one name from the harness/tools.py module.

09Troubleshooting

SymptomFix
'python' is not recognized…Python is not on PATH. Re-run the installer, choose Modify, tick Add Python to environment variables, and open a new terminal. Or use py -3.12.
Typing python opens the Microsoft StoreTurn off the App execution aliases for python.exe (see step 1).
running scripts is disabled on this systemSet-ExecutionPolicy -Scope CurrentUser RemoteSigned, or use Command Prompt with .venv\Scripts\activate.bat.
ModuleNotFoundError: No module named 'aisuite'The virtual environment is not active (no (.venv) in the prompt), or the notebook uses the wrong kernel. Activate, then pip install -r requirements.txt. In VS Code, pick the .venv kernel.
NameError: name 'is_mcp_config' is not definedaisuite was installed without the mcp extra. Run pip install -r requirements.txt again (it pins aisuite[openai,mcp]).
AuthenticationError / 401 / invalid_api_keyKey copied wrongly or still the placeholder. Check .env has no quotes or spaces, then restart the kernel so it re-reads .env.
RateLimitError / 429 / insufficient_quotaThe OpenAI account has no credit. Add billing at platform.openai.com.
Corporate network: SSLError, CERTIFICATE_VERIFY_FAILED, timeouts Your company inspects HTTPS traffic. pip 24.2 and newer already trusts the Windows / macOS certificate store, so upgrade pip first. If the upgrade itself fails with an SSL error, run it like this (the older pip that ships with Python understands this flag): 
python -m pip install --upgrade pip --use-feature=truststore
pip install -r requirements.txt
If you need a proxy: pip install --proxy http://proxy.company:8080 -r requirements.txt and set HTTPS_PROXY before running notebooks. If the API call fails with the same SSL error, run pip install truststore, add import truststore; truststore.inject_into_ssl() as the first line of the first notebook cell, or ask IT to allow api.openai.com.
Kernel takes a minute to start / VS Code says the kernel timed outEndpoint security scanning new files. Wait and retry; the repo's VS Code settings already allow 4 minutes. JupyterLab (Option A) is more patient.
VS Code: Could not initialize webview… service workerClose VS Code completely, delete %APPDATA%\Code\Service Worker, reopen. Or use JupyterLab instead.
Notebook cell stuck on [*] for minutesKernel → Interrupt, check your network, then re-run the cell.
Port 8501 is already in use (Streamlit)Another Streamlit is running. Stop it, or run streamlit run app.py --server.port 8502.
Wrong Python version in .venvDelete the .venv folder and repeat steps 3–4 with the right Python (py -3.12 -m venv .venv).
